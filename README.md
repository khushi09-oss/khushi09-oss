# Hi, I'm Khushi

I'm a machine learning engineer on the founding team at **Recollia**, where I build the ML core of an AI tutor for India's medical students: hybrid retrieval over clinical content, an LLM gateway, and the evaluation work that keeps quality honest.

I like the layer between a model call and a real user: state, tools, latency, grounding, evaluation. I also lead AI/ML at Google Developer Groups on Campus, where I teach workshops on agents and RAG.
